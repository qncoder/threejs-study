# ZF18000 Four-Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reusable ZF18000 four-link solver, a paste-ready verification script, and a dedicated debug route page for validating the mechanism on the current GLB.

**Architecture:** Keep the four-link math in `src/zf18000FourLinkMotion.js` as plain Three.js helpers, then build a standalone route page that loads `ZF18000.glb`, lets the user adjust the six node-name mappings and a single drive slider, and shows solver status. The first version uses the C++ `TwoFourLink` vertical-shaft style search logic and keeps the point mapping editable in the page instead of hard-coding it.

**Tech Stack:** Vue 3, Vite, Vue Router, Three.js, Vitest.
