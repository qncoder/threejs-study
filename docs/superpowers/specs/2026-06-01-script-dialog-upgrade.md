# 脚本编辑浮窗优化方案

## 背景

当前脚本编辑器是一个固定大小的浮动弹窗（760×760px），不透明背景完全遮挡 3D 视口，不能调整大小，关闭后位置不保留。用户的核心工作流是"改脚本 → 执行 → 看模型反应 → 再改"，弹窗遮挡视口是最大的打断点。

## 改动清单

### 1. 半透明毛玻璃背景

让用户透过弹窗看到模型运动效果，不需要关闭弹窗。

- `.floating-script-modal` 背景改为 `rgba(244, 241, 234, 0.72)` + `backdrop-filter: blur(12px)`
- Monaco Editor 区域保持不透明（代码必须清晰可读）
- 弹窗标题栏和操作按钮区域跟随半透明

### 2. 可调整大小

弹窗四角和四边可拖拽调整大小，Monaco Editor 已开启 `automaticLayout: true` 会自动适应。

- 使用 CSS `resize: both` 或自定义 resize handle（更可控）
- 最小尺寸：480×360px
- 最大尺寸：`calc(100vw - 32px)` × `calc(100vh - 32px)`
- 拖拽调整时需要更新 `clampDialogPosition` 的约束

### 3. 最小化到角标

不关闭弹窗、不丢失编辑状态，只是把弹窗收起来。

- 标题栏增加"最小化"按钮（标题栏现有：`关闭`，增加 `—` 最小化按钮）
- 最小化后弹窗变成一个小浮标：显示节点名 + `编辑脚本` 文字，固定在视口右下角
- 点击浮标恢复弹窗到原来的位置和大小
- 新增 `scriptDialog.minimized` 状态

### 4. 记忆位置和大小

重新打开弹窗时恢复到上次关闭时的位置和尺寸，减少每次重新拖拽的麻烦。

- 新增 `scriptDialogLayout` ref 存储 `{ x, y, width, height }`
- `openScriptDialog` 优先使用已存储的布局，没有时使用默认位置
- 布局信息不需要持久化到 sessionStorage（页面刷新后重置即可）

### 5. 透明度切换

一键在"半透明"和"不透明"之间切换，方便在需要专注写代码时切回不透明。

- 标题栏增加"透明"切换按钮
- 两档切换：半透明 (0.72) ↔ 不透明 (1.0)
- 新增 `scriptDialog.transparent` 状态

### 6. 最大化切换

一键铺满视口区域（不覆盖左右面板），用于需要大量编辑脚本的场景。

- 标题栏增加"最大化/还原"按钮
- 最大化时铺满 3D 视口区域（`viewer-panel` 的位置和大小）
- 还原回之前记忆的位置和大小
- 新增 `scriptDialog.maximized` 状态

## 涉及文件

| 文件 | 改动 |
|------|------|
| `src/styles.css` | `.floating-script-modal` 样式：半透明、resize handle、最小化浮标 |
| `src/App.vue` | 模板：最小化/最大化/透明按钮；脚本：布局记忆、最小化状态 |
| `src/dialogDrag.js` | 扩展：支持 resize 拖拽、尺寸约束 |

## 不改的部分

- Monaco Editor 组件 (`ScriptCodeEditor.vue`) 不需要改动，`automaticLayout: true` 会自动适应容器尺寸变化
- 脚本执行逻辑 (`nodeScriptControl.js`) 完全不变
- 右键菜单 → 打开脚本的数据流不变
- 整体三栏布局不变

## 标题栏按钮布局

```
┌─────────────────────────────────────────────────────────┐
│ 编辑脚本                          [透明] [—] [□] [×]   │
│ flap1_pos / Object3D                                    │
└─────────────────────────────────────────────────────────┘
  ↑ 可拖拽区域                       透明  最小 最大 关闭
```

┌──────────────────────────┐

└──────────────────────────┘
